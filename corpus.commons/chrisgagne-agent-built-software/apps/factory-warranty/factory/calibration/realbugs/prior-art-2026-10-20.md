Recorded so the README's "most-starred open-source AI reviewer we found" can be checked. Stars and licences from the
GitHub API (`gh api repos/{owner}/{repo}`) on 2026-10-20; they change daily.

How the list was found: GitHub repository search sorted by stars for "ai code review", "code review agent" and "pr
review llm" (`gh search repos "<query>" --sort stars`), plus reviewers named in earlier pre-registrations and ones we
already knew of (PR-Agent and Shippie don't come up in those searches, since their descriptions use other words). A
search like this can miss a tool; the claim is only about what we found.
