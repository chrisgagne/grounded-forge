## Not fixed, and why

- Runner-level test identity (16, 14): which tests ran, were skipped or failed is runner-specific; the gate checks runner config, exit codes and that the red output names each criterion's test.
- Model compliance (26): a reviewer can still be steered by text in the code it reads; the driver can only make its output strict and its inputs clean.
- Codex's reads (27): its read-only sandbox reads the whole disk; only what it could use is kept out of reach until both reviews finish.
- Non-repudiation (8): there is no signing key; the ledger is tamper-evident against the agents, not against someone with the operator's file access.
- Rollback truth (23): the rehearsal command's exit code is its own claim.
- Claude Code's per-user temp `/tmp/claude-UID` stays writable to every Claude leg; Claude Code forces it as the sandboxed `TMPDIR`.
- Hook failure blocking (5) waits on a Claude Code version that honours `onFailure`.
