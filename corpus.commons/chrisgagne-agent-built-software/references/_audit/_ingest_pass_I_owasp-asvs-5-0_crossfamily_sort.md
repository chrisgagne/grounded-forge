## 3. Remaining edits

Apply these exact replacements to `post-audit-deep.md`. Preserve surrounding text.

1. **Line 168 — CSP policy scope**

   Current:
   > and per-response nonces or hashes at L3

   Replacement:

2. **Line 171 — redirect scope**

   Current:
   > automatic redirects to other domains only to allowlisted destinations (3.7.2)

   Replacement:
   > automatic redirects to a different hostname or domain not controlled by the application only when the destination is allowlisted (3.7.2)

   Current:
   > no CR or LF in HTTP/2 or HTTP/3 header fields (4.2.4)

   Replacement:
   > acceptance only of HTTP/2 and HTTP/3 requests whose header fields and values contain no CR, LF or CRLF sequences (4.2.4)

   Current:
   > Files in public folders not executed as server-side code (5.3.1)

   Replacement:
   > Files uploaded or generated by untrusted input and stored in a public folder not executed as server-side program code when accessed directly through HTTP (5.3.1)

   Current:
   > file paths built from internal or trusted data, or strictly validated user filenames, against path traversal, LFI, RFI and SSRF (5.3.2)

   Replacement:
   > file paths built from internally generated or trusted data, or, if user-submitted filenames or file metadata must be used, with strict validation and sanitisation applied, against path traversal, LFI, RFI and SSRF (5.3.2)

6. **Line 199 — CSPRNG subjects**

   Current:
   > generated by a CSPRNG (6.5.3)

   Replacement:

   Replacement:
