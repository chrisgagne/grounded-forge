# OKF bundles

Open Knowledge Format (v0.2) interchange bundles emitted by the build from this corpus's compiled apps. Each directory is one self-contained bundle: markdown concept files with OKF frontmatter, reserved `index.md` routers, a licence manifest, and evidence markers preserved in-band. Regenerated by `npm run build`; deterministic (an unchanged corpus rebuilds byte-identical).

Start with [`matrix/`](matrix/) — all five task axes in one bundle, 116 concept files from 27 sources, the reference × task matrix expressed as directory structure. The five sibling bundles mirror the five compiled apps, one task axis each.

A bundle is the data layer only: any OKF-aware tool can read it, but the retrieval skills, lens application, and citation conduct live in the compiled apps under `apps/`. Why the format and this repo compose, and exactly what travels: [`docs/architecture/okf-interop.md`](../../../docs/architecture/okf-interop.md). How to emit your own: [`docs/how-to/emit-okf.md`](../../../docs/how-to/emit-okf.md).

Validate with the community CLI: `cargo install okf && okf validate matrix`.
