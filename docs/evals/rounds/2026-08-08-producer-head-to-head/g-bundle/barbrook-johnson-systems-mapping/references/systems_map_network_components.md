# Core terms

- **Model or map:** A purposeful simplification of an aspect or perception of reality. In systems mapping, “map” is commonly used as a synonym for “model.”
- **System:** A bounded set of elements and the processes or interrelationships between them. A system may also be understood as an interconnected set of elements organised to achieve a purpose.
- **Network:** A set of connected boxes or other elements. In a causal system map, connections are commonly directed arrows.
- **Node:** A box or element in a network. Depending on the mapping method, it may represent a variable, factor, concept, outcome, stock, or another system element.
- **Edge:** A connection, line, or arrow between nodes. In causal mapping methods, a directed edge represents cause or influence from its source node to its target node.

# Interpretation

The nodes and edges form the map’s representation of cause and influence. Their exact meanings are method-specific: some methods require variables that can increase or decrease, some attach probabilities or numerical weights, and some use more flexible concepts.
