# Facets

- **Attitude toward risk** — willingness to take chances while using technology; ranges from risk-averse to risk-tolerant.
- **Computer self-efficacy** — confidence in one's ability to use technology; ranges from low through medium to high.
- **Information processing style** — how a person gathers information in relation to acting on it; ranges from comprehensive to selective.
- **Learning style** — how a person prefers to move through software; ranges from process-oriented through mindful tinkering to tinkering.
- **Motivations** — what keeps a person using technology; ranges from task completion to interest in the technology itself.

# Values

A person's position on a facet is a **cognitive facet value**, also called a **cognitive style**. The Inclusivity Heuristics use the personas Abi, Pat, and Tim to represent different combinations of these values.
