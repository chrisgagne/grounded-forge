# Options

- **Constrain** — the constraint is fixed: it may improve, but it must not worsen.
- **Enhance** — seek improvement, such as taking less time, spending less, or delivering more scope.
- **Accept** — permit the constraint to worsen if necessary, such as taking more time, using more resources, or delivering fewer features.

# Dimensions

Apply one option to each dimension of the project's triple constraint:

- **Time** — project duration and intermediate deadlines.
- **Cost** — money, personnel, and other project resources.
- **Scope** — the project's intended accomplishments and requirements, including quality.
