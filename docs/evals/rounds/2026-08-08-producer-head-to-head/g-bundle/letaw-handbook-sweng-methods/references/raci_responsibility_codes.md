# Codes

- **R — Responsible**: performs the work.
- **A — Accountable**: approves the work and makes sure it gets done.
- **C — Consulted**: discusses the work and offers advice.
- **I — Informed**: receives updates about the work's status.

# Usage

A RACI matrix assigns these codes to roles for each task or deliverable. One person may hold multiple roles, and one role may receive multiple codes for a task.
