# Stages

- **Requirements** — determine and record what the software must do, how well it must do it, and the limitations or constraints it must respect.
- **Design** — determine how the code will be structured and how users will interact with the software.
- **Implementation** — use the requirements and design to build the software.
- **Testing** — verify that the code was built correctly and validate that the software is what users or the client need.
- **Maintenance** — improve the software's existing functionality and code.

# Process-model context

A software process model describes how a project moves through these stages. Agile uses short, repeated development cycles with frequent incremental releases, while Waterfall moves through the stages more linearly and sequentially.
