# Attributes

- **Maintainability** — the effort developers need to update, refactor, or otherwise modify the code.
- **Portability** — the effort needed to run the software on different platforms.
- **Reliability** — how often the software's functions succeed or fail.
- **Efficiency** — the amount of resources the software requires.
- **Integrity** — how frequently the software loses data.
- **Memorability** — the time users must spend relearning functionality.
- **Flexibility** — the number of different ways the software can be used.
- **Interoperability** — the ease with which the software integrates with other software.
- **Reusability** — the extent to which code can be used easily to solve other problems.

# Requirements usage

Convert an attribute into a testable nonfunctional requirement by defining a measurable threshold. For example, a reliability requirement may state that a function must succeed more than 99% of the time.
