# Types

- **Functional requirement** — describes behavior the system must exhibit under specified conditions; it answers, "What must the software do?"
- **Nonfunctional requirement** — describes a property or characteristic the system must exhibit, or a constraint it must respect; it answers, "How well must the software perform, or what limits must it obey?"

# Examples

- Functional: When the user activates the register button, add the user's information to the database and display a registration confirmation screen.
- Nonfunctional quality attribute: Response time must be a few seconds or less in all operating environments.
- Nonfunctional constraint: Data must be stored only on servers located in the United States.
