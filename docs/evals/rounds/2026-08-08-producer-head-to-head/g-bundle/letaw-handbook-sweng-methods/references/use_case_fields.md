# Required fields

- **Name** — a short title, often beginning with a verb, that states the user objective.
- **Actor(s)** — the human, nonhuman, or computer users interacting with the software.
- **Flow of events** — the sequence of actions describing the interaction between the actor and the software; also called the basic course of action or success scenario.

# Additional fields

- **Identifier** — a unique reference for the use case, such as `UC-002`.
- **Preconditions** — facts that must be true before the flow begins.
- **Postconditions** — facts that must be true after the flow ends.
- **Business relevance** — the justification for the use case.
- **Dependencies** — other use cases on which this use case relies.
- **Extensions** — contingencies, alternate routes, and branches to other use cases.
- **Priorities** — the importance of the use case.
- **Nonfunctional requirements** — how well the software must perform during the flow.
