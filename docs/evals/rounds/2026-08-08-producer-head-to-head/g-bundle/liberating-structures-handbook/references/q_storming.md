# How to run

1. Give everyone sticky notes.
2. Invite many courageous, provocative, silly, and apparently simple questions related to the meeting’s purpose, one legible question per note.
3. Post all questions on a wall.
4. Make sense of them by grouping, categorizing, prioritizing, reading them aloud, or discussing patterns in small groups.

# Generative prompts

- What question would you most like answered before leaving?
- Which question, if answered, would help you move forward or get unstuck?
- What must we address to make the choices ahead?
- What must be resolved before this initiative can start?

The resulting questions can seed a Just-in-Time Topics process.
