Simple rules are constraints that preserve what is essential while leaving room for creativity.

# Rule types

- How-to rules
- Boundary rules
- Priority rules
- Timing rules
- Exit rules

# How to run

1. Select an initiative, process, or activity that would benefit from reinvention.
2. Imagine handing it to a design team.
3. List the few things that must be present in any new design.
4. With a partner, test every proposed rule by asking what would happen if it were removed and whether it is truly required or merely inherited from current practice.
5. Debrief whether the group tends to over-specify or under-specify constraints.
