A Talking Object can be any convenient object passed among participants to make speaking turns explicit.

# Rule

Only the person holding the object speaks; everyone else remains silent. When finished, the speaker passes it to the next person who wishes to contribute. The object therefore supports an orderly and impartial hearing in which everyone who wants to speak can do so.

Using an ordinary, playful object can be more comfortable than borrowing a ceremonial talking stick from traditions where it has spiritual meaning.
