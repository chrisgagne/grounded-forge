Depreciation allocates the cost of a tangible asset over its useful economic life. It is a cost-allocation process, not a measurement of changes in fair market value.

# Inputs

- **Asset cost** — purchase price plus costs necessary to place the asset into service, such as shipping, taxes, setup, and installation.
- **Salvage or residual value** — the estimated value when the asset's useful life ends.
- **Depreciable base** — asset cost minus salvage value.
- **Useful life** — the time or productive capacity over which the asset is expected to be used.
- **Book value** — original cost minus accumulated depreciation.

# Method formulas

## Straight-line

Allocates an equal amount to each period:

```text
Annual depreciation = (Asset cost − Salvage value) / Useful life in years
```

## Units of production

Allocates cost according to actual usage:

```text
Depreciation per unit = (Asset cost − Salvage value) / Estimated lifetime output
Period depreciation = Depreciation per unit × Period output
```

## Double-declining balance

Accelerates depreciation into earlier periods:

```text
Double-declining rate = 2 × (100% / Useful life in years)
Period depreciation = Beginning book value × Double-declining rate
```

Salvage value is not subtracted before the initial double-declining calculation, but depreciation must stop before book value would fall below salvage value.

# Boundaries

Depreciation may be recorded annually, quarterly, or monthly. Land is not depreciated because it is treated as having an unlimited useful life. Regardless of the chosen method, total depreciation cannot exceed the depreciable base.
