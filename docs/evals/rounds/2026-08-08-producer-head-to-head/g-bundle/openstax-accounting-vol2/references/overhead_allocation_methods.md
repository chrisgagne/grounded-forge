# Predetermined Overhead

Manufacturing overhead includes indirect materials, indirect labor, and other factory costs that cannot be traced economically to one product. A predetermined rate permits product costing before actual period-end overhead is known.

```text
Predetermined overhead rate
  = Estimated manufacturing overhead / Estimated activity base

Applied overhead
  = Predetermined overhead rate × Actual activity
```

An activity base should have a cause-and-effect relationship with overhead. Common bases include direct labor hours, direct labor cost, machine hours, and units produced.

Applied overhead below actual overhead is **underapplied**; applied overhead above actual overhead is **overapplied**. The difference must be disposed of at period end, commonly through cost of goods sold.

# Traditional Allocation

Traditional allocation assigns factory overhead using one volume-related activity base. It is most informative when the selected base—often direct labor or machine hours—closely tracks how products consume overhead.

The method becomes less representative when products differ materially in complexity or when automation replaces direct labor with overhead-intensive equipment.

# Activity-Based Costing

Activity-based costing assigns overhead through multiple activity cost pools:

1. Identify activities that consume overhead resources.
2. Accumulate each activity’s costs in a cost pool.
3. Select a causal cost driver for each pool.
4. Compute a pool rate.
5. Apply each pool’s cost according to the product’s use of the driver.

```text
Activity rate
  = Estimated activity cost pool / Estimated driver quantity

Overhead assigned from a pool
  = Activity rate × Product driver usage
```

Common activity levels are:

- **Unit-level:** incurred for every unit, such as per-unit inspection.
- **Batch-level:** incurred for a production batch, such as machine setup.
- **Product-level:** supports a product line, such as engineering changes.
- **Factory-level:** sustains the facility, such as a production supervisor’s salary.
