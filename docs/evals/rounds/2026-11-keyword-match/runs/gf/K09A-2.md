"Fixes that fail" is a recurring system pattern: a quick fix eases a problem in the short run but creates side effects that make the same problem worse later. The main source here is the Social System Design Lab's *Systems Thinking Foundations* briefs (Farrell et al., 2021). Brief 1.07 lists it first of five archetypes and takes them from Daniel Kim's *Systems Archetypes I* (1993).

**Definition.** The briefs describe system archetypes as "visual descriptions of generic, recurring system structures in the form of Causal Loop Diagrams." Their definition of this one is:

> The "fixes that fail" archetype describes attempts to address a problem through a short-term fix. The fix might solve the problem in the short run, but it also generates unintended consequences that actually make the original problem worse.

**How it works.** It is built from two feedback loops:
- **The fix loop:** the problem gets worse, someone applies a fix, and the symptom eases. This loop works quickly.
- **The side-effect loop:** the same fix has a delayed side effect that feeds back into the original problem and makes it worse. That invites the fix again, so the cycle repeats.

The trap is the delay. The relief comes first, so the fix looks like it worked, and the damage shows up later.

**Worked example (Brief 1.07).** The brief uses exclusionary discipline in schools. A child who had a hard morning arrives late and is disruptive. The teacher sends her to time-out or the principal's office:

> The teacher is employing a short-term fix; they are removing the disruption from the classroom. However, over time the child becomes even more disengaged from school, feeling that there are no adults…

The rest of that sentence is lost in the converted text. The point is that the child's behaviour gets worse, which leads to more of the same discipline.

**A second example with the same structure (Brief 1.05).** A school district brings in a new curriculum to cut dropout rates. The briefs label this loop the "Short-term fix." The curriculum also adds a lot of work for teachers who are already overloaded. Over time they burn out, teaching quality drops, and dropout rates rise. The briefs call this second loop the "Unintended Consequence on Instruction."

**Related archetypes and cautions.**
- **Shifting the burden** is a close relative. There, the quick fix also makes it harder to invest in the real, upstream solution, so the quick fix becomes more and more tempting.
- **Use it as a hypothesis, not a label.** The briefs say archetypes are "not meant to erase the uniqueness of a situation." They also warn that using archetypes in workshops can set up an expert-versus-novice dynamic that overrides participants' own experience.
- **A second source agrees.** Barbrook-Johnson & Penn's *Systems Mapping* also lists "fixes that fail" among Kim's (2000) eight archetypes, the common patterns behind causal loop diagrams.
